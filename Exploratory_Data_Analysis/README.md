# EDA Project

This project is organized for maintainability and scalability.

## Structure

- `eda/` - Main package with core logic
- `ui/` - UI code (web, desktop, or notebook)
- `data/` - Data files (input/output)
- `tests/` - Unit tests
- `requirements.txt` - Python dependencies

## Getting Started

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the main script:
   ```bash
   python -m eda.main
   ```
3. (Optional) Add your UI code in `ui/app.py`.

---

Feel free to extend this structure as your project grows.
